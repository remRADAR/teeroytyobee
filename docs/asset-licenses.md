# Asset licenses and provenance

## Sofia Sans Extra Condensed

The site bundles the Latin upright and italic variable WOFF2 subsets at `public/fonts/SofiaSansExtraCondensed-latin.woff2` and `public/fonts/SofiaSansExtraCondensed-Italic-latin.woff2`. The original project uses this face as its poster-display family; restoring a local copy corrects its absent-font baseline and preserves the narrow editorial typography without a runtime third-party request.

The font is by Lettersoup, Botio Nikoltchev, and Ani Petrova. Copyright 2019 The Sofia Sans Project Authors. It is distributed under the SIL Open Font License 1.1; the complete notice is included in `public/fonts/OFL.txt`. The font is not sold separately.

The family and variable weights are documented by Google Fonts [1]. The upstream source repository describes the four width families and variable-font build [2]. The OFL terms and attribution are in the upstream license file [3]. The WOFF2 subsets were obtained from Google's CSS response and are self-hosted in the application.

## Teeroy portrait
