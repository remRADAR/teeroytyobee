# Animation and interaction report

## Public reference observations

The public-reference study documents an active Work-index project: selecting/hovering a different title changes the image and its metadata. Current route screenshots also confirm image-led project cards at 390 px, a desktop header with latest-work teaser, and a compact MENU/CLOSE mobile control. The public Journal, About and Contact pages have distinct editorial/image treatments. Exact hover duration, easing, event wiring, and Framer source settings remain unmeasured because the editor is inaccessible.

No reliable evidence confirms a custom cursor, parallax, autoplay, elaborate loading sequence, page curtain or specific route-transition choreography. These effects are not presented as reconstructed.

## Teeroy implementation

Primary and detail navigation, latest-release links, catalogue filters, newest-first lists, release details, verified outbound destinations and the user-triggered single-source player are retained. The mobile menu can be opened, dismissed with Escape, and closes after a route selection. Browser checks confirm its open state and navigation behavior.

The home selected-work module pairs a project list with a larger preview placeholder. Pointer hover and keyboard focus select a release and update its title/year/type. Missing releases do not switch to invented or uncleared cover images; the panel continues to say that approved release artwork is required. A dedicated 1280 px hover-state screenshot is generated by the responsive harness.

The user-requested intermittent glitch appears only as a decorative pseudo-element over the final word of the home masthead; accessible heading text remains `Teeroy Tyobee`. It is disabled for `prefers-reduced-motion`. The prior custom cursor, scroll rail and page curtain were removed from the app shell. No autoplay or multi-track radio is introduced. Press/media external links are user-initiated.
